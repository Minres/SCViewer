== Introduction

[#_overview]
=== SCViewer overview

SCViewer is a Eclipse based tool to display VCD, FST, and transaction streams. 
These traces can created by the SystemC VCD trace implementation and the SystemC Verification Library (SCV) as well as the FST and FTR (LWTR) implementations of the SystemC Components library.
For further description of the SCV please refer to 
http://www.accellera.org/activities/committees/systemc-verification.
For FST and FTR please have a look at https://github.com/Minres/SystemC-Components and https://github.com/Minres/LWTR4SC.


[#_features]
=== SCViewer features

Features include:

* loading of multiple trace files into the same waveform viewer
** VCD files (compressed and uncompressed)
** FST files 
** SCV/LWTR transaction recordings in various formats
*** text log files (compressed and uncompressed)
*** FTR files of LWTR (compressed and uncompressed)
*** sqlite based 
* Waveform visualization features
** various value representations of bit vectors (signed, unsigned, hex, bit)
** real numbers
** showing vectors and real numbers as analog (step-wise & continuous)
** grouping of signals and transactions
** combining signals and transactions to new waveforms
** visualization of transaction generators as trace
** inspection of transaction properties
** visualization of transaction relations
